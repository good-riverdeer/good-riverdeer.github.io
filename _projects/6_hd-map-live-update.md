## 3D Segmentation 기반 도로 객체 추출 모델

### 개발 목표

- 기존 이미지 기반 도로 객체 추출 과정에 3D Segmentation을 적용해 객체 추출 성능과 정밀지도 변경점 검출 성능을 향상시키는 것이 목표였습니다.
- 제한된 평면(Bird-Eye view, 전면 slice view 등)으로 구성된 이미지에 대한 육안 검수에서 발생하던 도로 객체의 위치 오차를 개선하고자 했습니다.
- 레이블 생성 비용이 큰 3D segmentation 작업의 특성상, 비교적 적은 양의 레이블만으로 학습이 가능한 방법이 필요했습니다.

### 개발 내용

- 기 구축된 정밀지도 정보를 Point Cloud 데이터에 투영해 Pseudo-labeled 데이터를 정의했습니다. 이때 기 구축된 정밀지도의 위치정보 자체를 100% 신뢰할 수는 없다는 전제를 두고 접근했습니다.
- Semi-supervised 3D segmentation 모델 중 하나인 ScribbleKitti 모델을 이 데이터에 적용했습니다.
- 기존에 위치좌표가 잘못 구축되어 있던 구간의 차선 등 도로 객체 위치정확도가 개선되는 것을 정성적으로 확인했습니다.
- 개발 결과물을 정밀지도 운영 조직에 공유했습니다.

## Metric Learning 기반 정밀지도 자동 검수 모델

### 개발 목표

- 100% 육안으로 진행 중이던 정밀지도 품질 검수 프로세스에 AI 도구를 도입하는 것이 목표였습니다.
- Bird-Eye view나 전면 slice view처럼 제한된 평면 이미지에 의존한 육안 검수로 인한 위치 오차를 개선하고, 넓은 정밀지도 구축 구간 내의 아주 작은 위치오차까지 검출할 수 있는 모델을 정의하고자 했습니다.

### 개발 내용

- Bird-eye view·전면 slice view에 제한되어 있던 기존 데이터 형태에서 벗어나, 육안 검수의 보조 자료로 쓰이던 카메라 좌표계로 Point Cloud를 투영해 데이터를 새로 정의했습니다.
- Triplet 데이터를 다음과 같이 구성했습니다.
  - **anchor**: Point Cloud를 2D로 투영한 이미지
  - **positive**: anchor에 기 구축된 정밀지도 객체를 투영한 이미지
  - **negative**: positive의 특정 정밀지도 객체를 고의로 오류가 발생하도록 변형한 이미지
- 이 triplet 구성으로 triplet loss 기반 metric learning을 수행해, 오구축된 정밀지도 객체가 포함된 구간을 검출하는 모델을 학습했습니다.
- 특정 고속도로 구간에 대해 5회 평균 **Average Precision 0.7815**를 달성했습니다.
- 개발 결과물을 정밀지도 운영 조직에 공유했습니다.
